# 拼豆图纸处理平台 · 使用指南

## 平台概述

拼豆图纸处理平台是一套完整的 Minecraft 拼豆图纸制作工具链，由**三大子系统**组成：

| 子系统 | 形态 | 用途 |
|--------|------|------|
| **Web 平台**（本平台） | Vue 3 本地应用 | 图纸导入 / 新建 / 编辑 / 管理 / 预览，浏览器 IndexedDB 本地存储 |
| **Fabric 模组** | 游戏内模组（Minecraft Java Edition 26.2） | 游戏内正交采样（截面 / 视图 / 截图），导出契约 JSON |
| **Python 工具** | 离线命令行脚本（`pattern-tool/`） | 纹理批量转图纸、动画帧拆分、契约 JSON 渲染 PNG |

三者通过统一的**契约 JSON 格式**互操作：模组 / Python 导出的 JSON 可直接导入 Web 编辑，Web 导出的 JSON 也可用 Python 渲染。

### 核心工作流程

1. **游戏内采样** -- 在 Minecraft 26.2 中安装 Fabric 模组，用 `/perler section` / `/perler view` 正交采样，或按 **F9** 一键截图
2. **导出 JSON** -- 模组自动用 MARD 色卡匹配豆号，导出契约 JSON 到 `.minecraft/patterns/`
3. **Web 编辑** -- 将 JSON 导入本平台，用多工具编辑器精修图纸
4. **导出成品** -- 导出高清 PNG 图纸或契约 JSON，交付拼豆制作

## 快速开始

### 导入图纸

1. 点击导航栏 **导入**（或首页 **导入图纸**）
2. 拖拽 / 选择契约 JSON 文件（支持粘贴文本）；也支持**直接导入图片**（PNG/JPG，设置长边像素数自动降采样生成图纸）
3. 自动校验格式，通过后存入本地图纸库并跳转编辑器

### 新建图纸

1. 首页或图纸库点击 **新建图纸**
2. 设置名称、宽度、高度（上限 256×256）、背景颜色（黑白灰预设 + 自定义取色器）
3. 进入编辑器开始绘制

### 浏览图纸

- **首页** -- 最近修改的图纸
- **图纸库** -- 全部图纸，搜索 / 排序 / 重命名 / 删除（带确认）/ 导出
- **官方图纸** -- 官方采样图库（3795 张），按分区浏览，一键导入本地
- **预览页** -- 点击任一图纸进入只读预览（缩放平移 + 颜色分布统计），可跳转编辑

## 编辑器工具

所有工具支持键盘快捷键：

| 工具 | 快捷键 | 说明 |
|------|--------|------|
| 画笔 | `B` | 基础绘制（按住拖动连续绘制） |
| 橡皮 | `E` | 擦除为背景色 |
| 填充 | `G` | 区域填充（洪水填充） |
| 取色器 | `I` | 从画布取色为当前色 |
| 矩形 | `R` | 拖拽框选区域填充 |
| 直线 | `L` | 拖拽绘制直线（Bresenham） |
| 平移 | `H` | 拖拽平移画布视图 |
| 替换 | `X` | 颜色替换（见下） |
| 选择 | `S` | 框选区域（配合复制/粘贴/删除） |

### 画笔尺寸

`[` / `]` 或工具栏按钮调整笔刷尺寸（1×1 / 2×2 / 3×3 / 4×4），画笔、橡皮、直线均生效。

### 颜色替换工作流

1. 按 `X` 或点替换工具 → 提示"点击画布选择要替换的颜色"
2. 点击画布上的**源颜色**格子 → 提示"源色已选，点击色板选目标色"
3. 点击色板中的**目标颜色** → 全图替换 → 提示"已替换 N 格"→ 自动切回画笔
4. 支持撤销（`Ctrl+Z`，单条历史）

### 选区 / 复制粘贴

- `S` 框选区域（虚线框预览）→ `Ctrl+C` 复制 → 移动光标 → `Ctrl+V` 粘贴（单条历史）
- `Delete` 删除选区内容（填充背景色）

### 图层（基础）

支持多层图纸：添加 / 删除（最少保留 1 层）/ 切换激活 / 可见性开关。当前渲染以激活图层为主，全图层合成渲染持续完善中。

## Fabric 模组（Minecraft Java Edition 26.2）

### 安装

1. 使用支持 Fabric 的启动器安装 **Minecraft 26.2 + Fabric Loader 0.19.3**（推荐 PCL2 等第三方启动器，安装 Fabric 时选 26.2）
2. 从 GitHub Releases 下载模组 JAR：<https://github.com/BoyangZhang619/mc-to-bean/releases>
3. 将 JAR 放入 mods 文件夹（注意启动器**版本隔离**时路径为 `.minecraft/versions/<版本>/mods/`）
4. 启动游戏（需 OP 权限执行命令，单机创造默认可用）

### 命令

```
/perler section <x1> <y1> <z1> <x2> <y2> <z2> [选项]        # 截面: 取平面本身
/perler view <x1> <y1> <z1> <x2> <y2> <z2> --direction <方向> --distance <N> [选项]   # 正交视图
/perler screenshot --long-edge <N>                          # 玩家视角截图
/perler screenshot config [--long-edge N] [--name 前缀] [--save 路径]   # 配置 F9 参数
/perler howtouse                                            # 游戏内帮助
```

**说明**：
- 两对角坐标定义轴对齐平面，**必须共面**（恰有一个轴相同）
- 方向合法性：竖直面（x 相同）→ `east|west`；竖直面（z 相同）→ `north|south`；水平面（y 相同）→ `up|down`
- `--distance` 探测距离（默认 16，上限 256）；`--ignore` / `--keep` 调整忽略集（默认忽略空气 / 屏障 / 结构空位）；`--granularity 1|2|4|8|16` 聚合粒度（面纹理内像素平均，16 = 1 方块 1 豆，1 = 纹理原样）；`--bg` / `--name` / `--save`
- **F9**：一键截图（画面干净无输入框），参数由 `/perler screenshot config` 配置

**采样取色（M5）**：模组解析方块模型文件，取**被看到那一面**的真实纹理像素并按 granularity 聚合——能看到木纹、石纹等细节（服务端版回退为 MapColor 平均色）。

**导出**：契约 JSON 保存到 `.minecraft/patterns/`，palette 已按豆号聚合并含 `bead_rgb`（豆号实际颜色）。

## Python 工具（离线）

`pattern-tool/` 目录下的命令行工具（需 Python 3 + Pillow）：

| 命令 | 用途 |
|------|------|
| `python entry.py` | 交互式入口（菜单引导） |
| `python texture_to_pattern.py <纹理.png> --palette mard` | 单张纹理 → 图纸 + JSON |
| `python json_to_pattern.py <图纸.json>` | 契约 JSON → 图纸 PNG |
| `python batch_convert.py` | 全量批量转换（assets 全部纹理，断点续跑） |
| `python split_animations.py` | 动画纹理逐帧拆分 |
| `python font_split.py` | 字体贴图按字符切分为图纸 JSON |

> Windows 中文乱码时：`PYTHONIOENCODING=utf-8 python ...`

## MARD 色卡

MARD 是国内拼豆圈主流的**通用色号体系**（非 Minecraft 专有）：**同一字母前缀 = 同一主题色系的不同深浅**。

| 前缀 | 色系 | 前缀 | 色系 |
|------|------|------|------|
| A | 黄 / 橙 | F | 红 |
| B | 绿 | G | 棕 / 肤 |
| C | 蓝 | H | 黑白灰 / 中性 |
| D | 紫 | M / P / R | 混合 / 珠光 / 透明 |
| E | 粉 | | |

共 291 色（如 A1 小布丁、B7 翡翠、H7 纯黑）。匹配算法：sRGB → **CIE Lab 最近邻**（人眼感知更准），Python 与模组端算法一致并交叉验证。模组端色卡内置于 JAR；Web 端色卡用于导入图片与导出匹配。

## 官方图纸库

官方图纸库收录 **3795 张** Minecraft 原版纹理的采样图纸，分区浏览：

- **Minecraft 方块**（1371）-- 建筑方块、矿石、木材、石材等
- **Minecraft 物品**（796）-- 工具、武器、食物、材料等
- **Minecraft 其他** -- 实体、GUI、环境、画等
- **花体符文** -- 游戏内符文文字逐字符图纸（支持用字体生成工具制作更精致的变体）

每张图纸可预览（缩放平移 + 颜色分布统计）并一键导入本地图纸库编辑。数据来自 `patterns/` 批量生成的契约 JSON（单行压缩，随 Web 构建发布）。

## 字体生成工具

**字体生成**页面可将字母表转换为像素图纸（制作"MC 符文风格"字母图纸）：

1. 选择字体（Georgia / Palatino / Garamond / Segoe Script / Baskerville / 自定义）
2. 配置：网格尺寸（12-36）、渲染字号（128-512）、二值化阈值、深底白字 / 白底黑字
3. 字符集：全部（A-Z a-z 0-9 标点）/ 仅大写 / 仅小写 / 仅数字 / 自定义
4. 实时像素预览（可放大查看）
5. 生成结果：**保存到图纸库**（可继续编辑）或下载契约 JSON

> 当前为拉丁字符集；支持中文（如果所选字体有效，比如自定义设置为“楷体”）。字符图纸文件命名 `gridsize{gs}_fontsize{fs}_fontshort{name}_U+XXXX_X.json`。

- **颜色列表** -- 图纸全部颜色，含**数量与百分比**统计（按豆号合并显示）

## 保存与导出

### 保存（手动）

修改**不会自动保存**——点保存按钮或 `Ctrl+S` 触发：保存时页面模糊遮罩 + 保存动画，完成后提示。标题旁红点表示有未保存修改。

### PNG 导出

导出菜单可选：

| 风格 | 说明 |
|------|------|
| PNG 完整面板 - Simple | 豆号色网格 + 每格豆号标注 + 图例（色块内嵌豆号 + 数量） |
| PNG 完整面板 - Detail | 原色网格 + 序号标注 + 图例（序号徽章 + 色块 + HEX） |
| PNG 完整面板 - Pure | 纯豆号色网格，无标注（图例只色块） |
| PNG 仅网格 | 简单网格导出 |

导出可调：单元格大小（默认 16px）、背景色、网格线。

### JSON 导出

契约 JSON（跨三端互操作）：

```json
{
  "name": "图纸名称",
  "width": 32, "height": 32,
  "cell_size_mm": 5,
  "bgColor": "#ffffff",
  "palette": [{ "index": 0, "rgb": [140,116,84], "code": "G17", "name": "G17", "delta": 11.25, "bead_rgb": [184,133,88] }],
  "grid": [[0, 1, ...], [...]]
}
```

## 常见问题

### 导入 JSON 提示格式错误？

确认文件是契约格式（含 `name` / `width` / `height` / `palette` / `grid`，palette 索引与 grid 匹配）。也可用**图片导入**替代。

### 为什么有些颜色实物中看起来不一样？

屏幕 RGB 与实物拼豆有色差。模组与 Web 用 MARD 色卡做 Lab 最近邻匹配，但显示器 / 豆子批次仍有差异，制作前建议对照实物色卡。

### 图纸最大尺寸？

新建上限 256×256。超大图纸建议分割。

### 手机上能用吗？

支持移动端浏览器：单指绘制、双指缩放平移、底部工具栏、色板抽屉。部分高级操作在移动端交互做了适配。

### 数据存哪里？

浏览器 IndexedDB 本地存储。清除浏览器数据会丢失图纸——**定期导出 JSON 备份**。

### 模组支持哪些版本？

当前模组仅支持 **Minecraft Java Edition 26.2**（Fabric Loader 0.19.3）。下载：<https://github.com/BoyangZhang619/mc-to-bean/releases>
